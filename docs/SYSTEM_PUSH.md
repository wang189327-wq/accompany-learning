# Android 系统通知

华为推送已接入。完整配置、云端函数上传和 APK 重建步骤见 [v1.3 部署教程](DEPLOY_V1_3.md)。

## 链路

学生网页提交 → 主接口生成老师消息 → 每分钟调度函数 → EMAS → 华为通道 → 老师 Android 系统通知。设备按安装标识、包名和当前身份绑定，通知点击跳转到对应作业。

通用发布 APK 包含推送 SDK 和完整代码，不含个人平台参数。部署者必须创建自己的 EMAS／华为应用，填写被忽略的本地配置后重新构建。云端地址和 App 访问码在 App 的连接设置填写；SDK 参数在构建前配置，两者用途不同。

RAM 凭据、华为 Client Secret 只保存在云端或平台控制台；配置后的自建 APK 按 SDK 设计包含部署者自己的客户端初始化参数。不要公开本地配置或带私人参数的自建 APK。

## 行为

- 老师、学生设备分别绑定当前身份，切换角色后更新绑定。
- 注册前历史消息、已读消息不推送；重试使用设备级发送记录去重。
- 通知显示标题与通用提醒，不显示正文和评分。
- 未配置时明确提示配置后重新构建；不把 SDK 注册或云端受理当作设备已显示通知。
- 通知权限、系统强行停止、省电策略、厂商通道权限及网络会影响送达。

接口和消息来源保持 cloud build 1；定时函数 `index.handler` 每分钟调用独立凭据保护的 `/api/push/dispatch`。具体参数、权限示例、包名与证书要求见部署教程。
