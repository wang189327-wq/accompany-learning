# 系统消息通知实现计划

目标：C9、Accompany Learning 自用版和 GitHub 公开源码提供同一套应用外通知功能。设备为 vivo X100s Pro、华为 MatePad 11.5S / HarmonyOS 4.2。

已确认：用户采用阿里云移动推送；尚未开通 EMAS，先交付程序和部署包。此前版本的应用内消息继续作为消息记录来源。

架构：云端保存按安装设备、应用包名、当前角色绑定的推送设备ID；定时触发器扫描现有消息并通过阿里云通知接口推送。安卓使用阿里云SDK及华为、vivo辅助通道，申请通知权限，提供通知设置及点击跳转。敏感服务器权限只保存在函数环境变量/执行角色；客户端只使用SDK必需的应用配置。

- [x] 云端设备绑定、解除、状态查询；权限和参数校验。
- [x] 阿里云RPC调用；设备级消息去重、重试和通知标识。
- [x] 独立定时触发入口，支持应用关闭后的截止提醒。
- [x] Android Gradle 推送构建入口，保留普通构建；配置文件排除公开版本控制。
- [x] Application初始化阿里云、华为和vivo通道；通知权限、系统设置、点击跳转。
- [x] 同步角色和连接变更，防止切换角色后收到旧身份通知。
- [x] 三份工程同步、部署包、示例配置和逐步开通文档。
- [x] 模拟服务验证绑定/去重/失败重试/身份切换；源码和打包检查。
